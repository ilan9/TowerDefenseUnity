# Tower Defense

Premier projet d'apprentissage réalisé sur **Unity**. Ce petit jeu de **Tower Defense** très classique a été conçu dans le but de découvrir les bases du moteur, son interface et ses mécaniques fondamentales.

## Principe du jeu

Le joueur doit défendre sa base contre des vagues d'ennemis en plaçant stratégiquement des tours défensives le long de leur parcours afin d'empêcher qu'ils n'atteignent la fin du chemin.

## Objectifs de ce projet

* Découvrir l'environnement et le fonctionnement de **Unity**
* Mettre en place les mécaniques de base d'un **Tower Defense** (vagues d'ennemis, ciblage, gestion des tirs et des ressources)
